# Agilo support

Agilo is an Azure DevOps extension for SAFe programs and squads.

## Get help or report a problem

Open an issue: https://github.com/eslam-sa3d/agilo-support/issues/new

Please include:

- Azure DevOps Services or Azure DevOps Server (and its version, for example 2022.1)
- The process the project uses (Agile, Scrum, CMMI, Basic, or an inherited process)
- The Agilo page and tab, what you did, what you expected and what happened
- A screenshot, with any confidential data removed

Do not post passwords, tokens or confidential work item content in an issue: issues are public.
